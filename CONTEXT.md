# Glossar — dv-forge Reviews

Begriffe der dv-forge-Reviews für Spec und Plan.

| Begriff | Bedeutung | Nicht verwenden |
|---|---|---|
| **Lauf** | Ein Aufruf eines Reviews, vom Start bis zum Bericht. | |
| **Runde** | Ein Review-Schritt innerhalb eines Laufs. Runde 1 sucht, Runde 2 ist die Nachprüfung. | Durchlauf |
| **Nachprüfung** | Prüft nur, ob die gemeldeten Punkte erledigt sind. Sie sucht nicht neu. | Nach-Review, Re-Review |
| **Hinweis** | Ein Finding der Stufe 🟡. Es blockt nicht; die Entscheidung fällt später, etwa im Plan. | |
| **Kategorie** | Die Art eines Findings aus einer festen Liste. Sie bestimmt, ob das Finding blockt. | |
