# dv-angular

Angular-Skills für Claude Code: moderne Komponenten, Signals, Routing, Forms, Styling, Testing und Toolchain (Angular v20+).

## Skills

| Gruppe | Skills |
|---|---|
| Grundlagen | `angular`, `angular-new-project`, `angular-cli`, `angular-project-layout`, `angular-migration` |
| Komponenten und UI | `angular-component`, `angular-styling`, `angular-material`, `angular-a11y` |
| State und Daten | `angular-signals`, `angular-signal-architecture`, `angular-di`, `angular-forms`, `angular-routing` |
| Testing | `angular-testing`, `angular-testing-jest-conventions`, `angular-testing-vitest-conventions` |
| Toolchain | `toolchain` (bauen, testen, linten), `init` (Projekt einrichten) |

Zusätzlich liegen unter `bin/`, `scripts/` und `hooks/` die Hilfsmittel der Toolchain, unter `tests/` deren Tests.

## Einrichten

```text
/plugin install dv-angular@dv-ai-development
```

Danach im Projekt `/dv-angular:init` ausführen.
