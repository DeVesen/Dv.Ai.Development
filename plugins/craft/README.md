# dv-craft

Software-Design-Skills für Claude Code: Leitplanken für Architektur- und Designentscheidungen, Clean Code und Testing.

## Skills

| Skill | Wofür |
|---|---|
| `craft` | Einstieg: verweist je nach Frage auf den passenden Craft-Skill |
| `craft-design-principles` | DDD, IODA, SOLID, Flow Design, Vorrang bei Prinzipien-Konflikten |
| `craft-clean-code` | Lesbarkeit, Benennung, Struktur |
| `craft-architecture-styles` | Layered, Hexagonal, Vertical Slice, Modulith, Microservices und weitere als Nachschlagewerk |
| `craft-modulith-thinking` | Fachliches Modulith-Modell: Abteilungen, Grenzen, Kommunikation |
| `craft-dotnet-modulith-bridge` | Modulith-Modell auf eine .NET-Struktur abbilden |
| `craft-angular-modulith-bridge` | Modulith-Modell auf eine Angular-Struktur abbilden (`features/`, `core/`, `shared/`) |
| `craft-unit-testing` | Unit-Tests, AAA, TDD |
| `craft-integration-testing` | Integrationstests |

## Einrichten

```text
/plugin install dv-craft@dv-ai-development
```
