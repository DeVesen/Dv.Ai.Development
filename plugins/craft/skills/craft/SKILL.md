# Craft

Software-Design-Skills. Thema → passenden Skill per Skill-Tool aufrufen.

| Thema | Skill |
|-------|-------|
| Naming, Kommentare, Formatierung, DTOs, Fehlerbehandlung, Code-Smells | `craft-clean-code` |
| Architektur, DDD, IODA/IOSP, SOLID, Flow Design, Komponenten-Struktur | `craft-design-principles` |
| Integrationstests, TestContainers, WebApplicationFactory, DB-Rollback | `craft-integration-testing` |
| Unittests, AAA, TDD, Testklassen/-methoden-Naming | `craft-unit-testing` |
