# Craft

Software-Design-Skills. Thema → passenden Skill per Skill-Tool aufrufen.

| Thema | Skill |
|-------|-------|
| Naming, Kommentare, Formatierung, DTOs, Fehlerbehandlung, Code-Smells | `craft-clean-code` |
| DDD, IODA/IOSP, SOLID, Flow Design, Komponenten-Struktur | `craft-design-principles` |
| Integrationstests, TestContainers, WebApplicationFactory, DB-Rollback | `craft-integration-testing` |
| Unittests, AAA, TDD, Testklassen/-methoden-Naming | `craft-unit-testing` |
| Layering, Deployment, Data-Flow, Hexagonal, Modulith, CQRS | `craft-architecture-styles` |
| Unternehmen/Abteilungen, Konzern/Tochterunternehmen, Modulith-Geschäftssprache | `craft-modulith-thinking` |
| Feature-Struktur, core/shared, Cross-Feature-Grenzen (Angular) | `craft-angular-modulith-bridge` |
| .csproj-Zuschnitt, Zimmertiefe, Contracts, SharedKernel (.NET) | `craft-dotnet-modulith-bridge` |
