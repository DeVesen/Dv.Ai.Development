<beschreibung>

Dieses Plugin wird von der Plugin-Druckerei aus den Quellen in `src/<ordner>` gedruckt. Änderungen gehören in die Quellen, nicht in die gedruckten Dateien; nach jeder Änderung prüft `druckerei pruefen`, ob alles zusammenpasst.
