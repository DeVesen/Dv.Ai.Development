# dv-working-capturing

Projektwissen festhalten, solange es frisch ist: Begriffe, Module und Features werden in Projektdokumenten erfasst, damit spätere Arbeit nicht von vorn suchen muss.

## Skills

| Skill | Wofür |
|---|---|
| `working-capturing` | Einstieg: verweist auf den passenden Capturing-Skill |
| `actual-knowledge` | Capture-Durchgang über die aktuelle Session: was ist erfassenswert? |
| `glossary` | Ein Begriff oder eine Abkürzung gehört zu einer Datei, einem Service oder einem Konzept |
| `module-profile` | Wofür ein Build-Artefakt (Service, Bibliothek, Executable) da ist und wie es gebaut wird |
| `feature-profile` | Was ein Feature kann und welche Bereiche es umfasst |
| `update` | Projektdokumente nach neuen Commits auf dem Branch nachziehen |

Die Profile sind die Grundlage, gegen die `dv-forge` Specs prüft (`spec-review-profiles`).

## Einrichten

```text
/plugin install dv-working-capturing@dv-ai-development
```
